---
title: 高速入出力
category: テンプレート
description: まとめて読む高速な入力と、ためて最後に書く出力
order: 1
---

提出するコードの先頭に貼るテンプレートです。最初に標準入力をすべて読んで空白・改行で区切り、トークンを先頭から 1 つずつ取り出します。出力はリストにためておき、プログラムの終了時（`atexit`）にまとめて書き出します。`input` と `print` を置き換えるので、残りのコードは普段どおりに書けます。

- `input()`, `SI()`: 次のトークンを文字列で返す。トークンがもうなければ `EOFError` を投げる
- `II()`: 次のトークンを整数で返す
- `LI(n)`: 次の $n$ 個のトークンを整数のリストで返す
- `LLI(h, w)`: $h$ 行 $w$ 列の整数を 2 次元リストで返す
- `print(*args, sep=' ', end='\n', file=None, flush=False)`: 組み込みの `print` と同じ引数で、出力をためる。`flush=True` でためた分をすぐ書き出す。`file` に標準出力以外（`sys.stderr` など）を渡したときは、ためずに組み込みの `print` で書く
- `io.flush()`: ためた出力を書き出す。終了時に自動で呼ばれる
- 計算量: どれも 1 トークンあたり $O(1)$

`input()` は 1 行ではなく 1 トークンを返すので、空白を含む行を 1 行まるごと読むことはできません。 $1$ 行に $N$ 個並んだ整数は `LI(n)` のように個数を指定して読みます。最初に入力を EOF まで読むので、インタラクティブな問題には使えません。

例:

```python
n, q = II(), II()
a = LI(n)
for _ in range(q):
    t = II()
    if t == 1:
        i, x = II(), II()
        a[i] = x
    else:
        print(sum(a))
```
