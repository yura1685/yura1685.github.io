---
title: 長方形の和集合の面積
category: 幾何
description: 軸に平行な長方形の和集合の面積を $O(N \log N)$ で求める
order: 9
---

長方形の左端と右端を $x$ 座標の小さい順に見ていきます（走査線）。 $y$ 座標を座標圧縮し、隣り合う $y$ 座標の間の区間ごとに、今の $x$ でそこを覆っている長方形の個数をセグ木で持ちます。長方形の左端で $[d, u)$ に $1$ を足し、右端で $1$ を引きます。個数はどこも $0$ 以上なので、覆われていない長さは、個数の最小値が $0$ ならその最小値になる部分の長さで、そうでなければ $0$ です。そこで各ノードには、区間の個数の最小値と、最小値になる部分の長さを持たせます。区間に足すだけで、答えは根でしか見ないので、足した値はノードに残したまま子には伝えません。再帰は使いません。

- `rectangle_union_area(rects)`: 長方形のリスト `rects = [(l, d, r, u), ...]`（ $l \le x < r$ かつ $d \le y < u$ の範囲で、座標は整数）の和集合の面積を返す。 $l \ge r$ や $d \ge u$ の長方形（面積 $0$）は無視する。 $O(N \log N)$

マス目の $x_1 \le x \le x_2$ かつ $y_1 \le y \le y_2$ の部分を塗るときは `(x1, y1, x2 + 1, y2 + 1)` を渡すと、塗られたマスの個数になります。

ACL の遅延セグ木で書くときは、 [遅延セグ木（ACL）の使い方](lazy_segtree.html) の「区間加算・区間最小値とその個数」で、個数の代わりに長さを数えます。

例:

```python
print(rectangle_union_area([(0, 0, 2, 2), (1, 1, 3, 3)]))  # 7
print(rectangle_union_area([(0, 0, 4, 4), (1, 1, 2, 2), (-3, 0, -1, 1)]))  # 18
```
