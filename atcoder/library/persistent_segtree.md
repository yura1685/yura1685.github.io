完全二分木の葉に列を置き、各ノードにはその区間の値を `op` でまとめたものを持たせます。1 点を更新するときは、根からその葉までの道にあるノードだけをコピーして新しい根を作り、残りの部分木は前の版と共有します（経路コピー）。前の版はそのまま残り、どの版からでも新しい版を作れます。ノードはオブジェクトにせず、子の番号と値をリスト `lch`, `rch`, `d` に持たせています。

`op` と `e` は ACL のセグ木と同じで、`op` は結合的な演算（可換でなくてよい）、`e` はその単位元です。版の番号は整数で、最初の列が版 $0$ です。`set` を呼ぶたびに $1, 2, \dots$ と増えます。区間はすべて半開区間 $[l, r)$ です。

- `PersistentSegTree(a, op, e)`: 列 $a$ を版 $0$ として作る（ $N$ は $a$ の長さ）。 $O(N)$
- `set(ver, p, x)`: 版 $\mathrm{ver}$ の $a_p$ を $x$ にした新しい版を作り、その番号を返す（版 $\mathrm{ver}$ は変わらない）。 $O(\log N)$
- `get(ver, p)`: 版 $\mathrm{ver}$ の $a_p$。 $O(\log N)$
- `prod(ver, l, r)`: 版 $\mathrm{ver}$ の `op(a[l], ..., a[r - 1])`（ $l = r$ なら `e`）。 $O(\log N)$

`set` 1 回でノードが $O(\log N)$ 個増えるので、 $Q$ 回更新したときのメモリは $O(N + Q \log N)$ です。

`RangeKth`（区間で $k$ 番目に小さい値）:

値を座標圧縮して、版 $i$ が「 $a$ の先頭 $i$ 個に各値がいくつあるか」を持つ永続セグ木を作ります。 $a_l, \dots, a_{r-1}$ に各値がいくつあるかは版 $r$ と版 $l$ の差なので、2 つの版の根から同時に降りて、左の子の個数の差が $k$ より大きければ左へ、そうでなければその個数を $k$ から引いて右へ進みます。降りるときに見るのは左の子の個数だけなので、各ノードにはそれだけを持たせています。

- `RangeKth(a)`: 列 $a$ から前計算。 $O(N \log N)$ 時間・メモリ
- `kth(l, r, k)`: `a[l:r]` の小さい方から $k$ 番目（0-indexed、 $0 \le k < r - l$）の値。 $O(\log N)$

区間で $k$ 番目に小さい値は [Wavelet Matrix](wavelet_matrix.html) でも求められます（どちらも値の更新はできません）。Wavelet Matrix では、ある範囲に入る値の個数や和なども求められます。`RangeKth` は値を座標圧縮するので、負の値や大きな値もそのまま渡せます。

2 つのクラスは互いに使っていないので、使う方だけを貼れば動きます。

例:

```python
seg = PersistentSegTree([3, 1, 4, 1, 5], lambda x, y: x + y, 0)
v1 = seg.set(0, 1, 9)  # 版 0 の a[1] を 9 にした版
v2 = seg.set(0, 4, 0)  # 版 0 から枝分かれ
print(seg.prod(0, 0, 5), seg.prod(v1, 0, 5), seg.prod(v2, 1, 5))  # 14 22 6
print(seg.get(v1, 1), seg.get(0, 1))  # 9 1

rk = RangeKth([5, 2, 8, 2, 7, 1])
print(rk.kth(1, 5, 0), rk.kth(1, 5, 2), rk.kth(0, 6, 5))  # 2 7 8
```
