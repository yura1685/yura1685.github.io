回文の対称性を使って、各位置を中心とする最長回文の半径を $O(N)$ で求めます。文字の間に区切りを入れることで、偶数長の回文も扱います。文字列だけでなく、整数のリストなどにも使えます。

- `manacher(s)`: `r[i]` が「`s[i]` を中心とする奇数長の最長回文の半径」（`s[i - r[i] + 1:i + r[i]]` が回文）であるリストを返す。 $O(N)$
- `palindromes(s)`: 長さ $2N - 1$ のリスト `res` を返す。`res[c]` は中心が $c / 2$ の最長回文の長さで、 $c$ が偶数なら `s[c // 2]` が中心、奇数なら `s[c // 2]` と `s[c // 2 + 1]` の間が中心。 $O(N)$

`s[l:r]` が回文かどうかは、`palindromes(s)[l + r - 1] >= r - l` で判定できます（ $l < r$）。
