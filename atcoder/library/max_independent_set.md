まだ選ぶかどうか決めていない頂点の集合をビットで持ちます。その中で次数が $1$ 以下の頂点があれば、それを選んで隣の頂点とともに取り除きます（そうしても答えの大きさは変わりません）。次数がすべて $2$ なら閉路だけが残っているので、どの頂点を選んでもかまいません。そうでなければ次数が最大の頂点 $v$ について、「 $v$ を選び、 $v$ とその隣を取り除く」「 $v$ を選ばず、 $v$ だけを取り除く」の 2 通りに分けて調べます。再帰は使いません。 $N$ は 40 程度までが目安です。

- `max_independent_set(n, edges)`: 頂点数 $n$ と無向辺のリスト `edges = [(u, v), ...]` のグラフの最大独立集合を 1 つ、頂点番号の昇順のリストで返す。自己ループのある頂点は選ばない。 $O(1.381^N N^2)$

計算量の式は最悪の場合で、多くのグラフではずっと速く終わります。

最大クリーク（どの 2 頂点も辺で結ばれている頂点の集合のうち最大のもの）は、補グラフ（辺で結ばれている 2 頂点と結ばれていない 2 頂点を入れ替えたグラフ）の最大独立集合です。また、最大独立集合に入らない頂点の集合は、最小頂点被覆（どの辺も少なくとも一方の端が入っている頂点の集合のうち最小のもの）になります。

例:

```python
n = 6
edges = [(0, 1), (0, 2), (0, 3), (1, 2), (1, 3), (2, 3), (3, 4), (3, 5), (4, 5)]
S = max_independent_set(n, edges)
print(S)  # [0, 4]
print([v for v in range(n) if v not in S])  # 最小頂点被覆 [1, 2, 3, 5]

# 最大クリーク: 補グラフの最大独立集合
E = set((min(u, v), max(u, v)) for u, v in edges)
comp = [(u, v) for u in range(n) for v in range(u + 1, n) if (u, v) not in E]
print(max_independent_set(n, comp))  # [0, 1, 2, 3]
```
