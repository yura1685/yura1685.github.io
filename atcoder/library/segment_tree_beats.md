---
title: Segment Tree Beats
category: データ構造
description: 区間 chmin・区間 chmax・区間加算と、区間の和・最大値・最小値を求めるセグ木。各操作ならし $O(\log^2 N)$
order: 20
---

各ノードに、その区間の最大値・2 番目に大きい値・最大値の個数と、最小値の側の同じもの、区間の和、子にまだ足していない値を持たせます。区間 chmin で $x$ を受け取ったとき、 $[l, r)$ に入っているノードでは、最大値 $M$ が $x$ 以下なら何もしません。2 番目に大きい値が $x$ より小さければ、変わるのは $M$ に等しい値だけなので、和に $(x - M) c$ を足して（ $c$ は $M$ の個数）最大値を $x$ にし、子には降りません。どちらでもないときだけ子に降ります。chmax も同じです。値が 1 種類か 2 種類のノードでは、最大値を変えると最小値や 2 番目に小さい値も変わる（逆も同じ）ので、そこも合わせて直しています。

子に降りる回数は全体でならすと抑えられ、 $Q$ 回の操作全体で $O((N + Q) \log^2 N)$、つまり各操作ならし $O(\log^2 N)$ です。ノードはオブジェクトにせず、値をリスト `mx1`, `mx2`, `mxc`, `mn1`, `mn2`, `mnc`, `sm`, `lz` に持たせています。子に降りるときは再帰を使わず、スタックで降ります。

区間はすべて半開区間 $[l, r)$ です。値の絶対値は $2^{62}$ 未満とします（番兵に $\pm 2^{62}$ を使っています）。

- `SegmentTreeBeats(a)`: 列 $a$ で初期化する（ $N$ は $a$ の長さ）。 $O(N)$
- `chmin(l, r, x)`: $l \le i < r$ の各 $a_i$ を $\min(a_i, x)$ にする。ならし $O(\log^2 N)$
- `chmax(l, r, x)`: $l \le i < r$ の各 $a_i$ を $\max(a_i, x)$ にする。ならし $O(\log^2 N)$
- `add(l, r, x)`: $l \le i < r$ の各 $a_i$ に $x$ を足す。ならし $O(\log^2 N)$
- `sum(l, r)`: $a_l + \dots + a_{r-1}$（ $l = r$ なら $0$）。 $O(\log N)$
- `max(l, r)`: $\max(a_l, \dots, a_{r-1})$（ $l = r$ なら $-2^{62}$）。 $O(\log N)$
- `min(l, r)`: $\min(a_l, \dots, a_{r-1})$（ $l = r$ なら $2^{62}$）。 $O(\log N)$

1 点の値は `sum(p, p + 1)` で求められます。区間の値をすべて $x$ にする（区間更新）ときは、`chmin(l, r, x)` と `chmax(l, r, x)` を続けて呼びます。区間加算と区間和だけなら [遅延セグ木](lazy_segtree.html) の方が速いです。

例:

```python
seg = SegmentTreeBeats([3, 1, 4, 1, 5, 9, 2, 6])
seg.chmin(0, 8, 4)  # [3, 1, 4, 1, 4, 4, 2, 4]
seg.chmax(2, 6, 3)  # [3, 1, 4, 3, 4, 4, 2, 4]
seg.add(1, 4, 10)  # [3, 11, 14, 13, 4, 4, 2, 4]
print(seg.sum(0, 8), seg.max(0, 8), seg.min(4, 8))  # 55 14 2

# 区間更新（a[2:5] をすべて 7 にする）
seg.chmin(2, 5, 7)
seg.chmax(2, 5, 7)
print(seg.sum(0, 8), seg.sum(2, 5))  # 45 21
```
