---
title: 全方位木DP
category: 木
description: すべての頂点について、その頂点を根としたときの木 DP の値を O(N) で求める
order: 4
---

根を 1 つ決めて下から木 DP をしたあと、上から「親の側の部分木の値」を配ることで、すべての頂点を根としたときの値を求めます。再帰は使いません。問題ごとに次の 3 つを決めて渡します。

- `merge(a, b)`: 子から来た値をまとめる演算（結合的かつ可換）
- `e`: `merge` の単位元
- `add_root(x, v, p)`: 子の値をまとめた $x$ に頂点 $v$ を加えて、隣の頂点 $p$ へ渡す値を返す。 $p = -1$ のときは、 $v$ を根としたときの答えを返す

関数は次の 1 つです。

- `rerooting(g, merge, e, add_root)`: 木の隣接リスト `g[v] = [to, ...]` から、各頂点を根としたときの答えのリストを返す。 $O(N)$（`merge` と `add_root` が $O(1)$ のとき）

値には整数やタプルのような、書き換えないものを使います。辺の重みを使うときは、`add_root` の中で辺 $(v, p)$ の重みを足します（重みは `(v, p)` をキーとする辞書などで引きます）。

例（各頂点から他のすべての頂点への距離の和）:

```python
def merge(a, b):
    return (a[0] + b[0], a[1] + b[1])


def add_root(x, v, p):
    # x = (子の側の頂点数, v からその頂点たちへの距離の和)
    if p == -1:
        return x
    return (x[0] + 1, x[1] + x[0] + 1)


res = rerooting(g, merge, (0, 0), add_root)
# res[v][1] が v から他のすべての頂点への距離の和
```
