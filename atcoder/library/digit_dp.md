title: 桁 DP
category: DP
description: $n$ 以下の整数のうち、上の桁から読んでいったときの状態が条件を満たすものの個数を、状態をタプルにして辞書で持つ DP で数える
order: 9
---

上の桁から 1 桁ずつ数字を決めていき、「ここまで $n$ と同じ数字か（この先の数字に上限があるか）」と「すでに 0 でない数字が出てきたか」と、問題ごとの状態の組ごとに個数を持ちます。状態は辞書のキーにするので、条件がいくつあってもタプルにまとめて持てます。実際に現れた状態だけが辞書に入るので、すべての状態の表を作るよりも軽く済みます。問題ごとに次の 3 つを決めて渡します。

- `init`: まだ何も読んでいないときの状態
- `step(state, d)`: 状態 `state` で次の桁の数字 $d$ を読んだあとの状態を返す関数。その先を数えなくてよいときは `None` を返す
- `accept(state)`: すべての桁を読んだあとの状態 `state` を数えるかを返す関数

関数は次の 1 つです。

- `digit_dp(n, init, step, accept, mod, base)`: $0$ 以上 $n$ 以下の整数のうち、上の桁から `step` で状態を進めた結果が `accept` を満たすものの個数を返す。 $n$ は整数か、 $10^{10000}$ のように大きいときは数字の文字列で渡す。`mod` を渡すと個数を `mod` で割った余りで返す（省略すると割らない）。`base`（既定は $10$）進数で考える。 $O(LSB)$

ここで $L$ は $n$ の桁数、 $S$ は 1 つの桁で現れる状態の種類数、 $B$ は `base` です。先頭の $0$ は読まないので、 $x = 0$ の状態は `init` のままで、`accept(init)` が `True` なら $x = 0$ も数えます。 $l$ 以上 $r$ 以下の個数は、 $r$ 以下の個数から $l - 1$ 以下の個数を引いて求めます。

条件の数が多くても、状態のタプルが長くなるだけで、同じように書けます。ただ、 $S$ が数十万を超えると辞書の出し入れが重くなるので、そのときは状態を整数にまとめて配列で持つ DP を直接書く方が速いです。条件を満たせなくなった状態は、`step` で `None` を返してすぐに捨てると、 $S$ が小さくなります。個数ではなく、条件を満たす整数の和などが欲しいときは、辞書の値を (個数, 和) の組にするように書き換えます。

例（ABC 154 E。 $1$ 以上 $n$ 以下で、 $0$ でない数字がちょうど $k$ 個の整数の個数）:

```python
def step(s, d):
    s += d != 0
    return s if s <= k else None


ans = digit_dp(n, 0, step, lambda s: s == k)
```

例（EDPC S。 $1$ 以上 $K$ 以下で、各桁の和が $D$ の倍数の整数の個数を $10^9 + 7$ で割った余り。 $K < 10^{10000}$ なので文字列で渡す）:

```python
ans = (digit_dp(K, 0, lambda s, d: (s + d) % D, lambda s: s == 0, 10**9 + 7) - 1) % (10**9 + 7)
```

$x = 0$ も数えられてしまうので $1$ を引いています。

例（ $1$ 以上 $n$ 以下で、 $3$ の倍数か、 $3$ を含む整数の個数。状態は「各桁の和を $3$ で割った余り」と「 $3$ が出てきたか」の組）:

```python
def step(st, d):
    r, has3 = st
    return ((r + d) % 3, has3 or d == 3)


ans = digit_dp(n, (0, False), step, lambda st: st[0] == 0 or st[1]) - 1
```
