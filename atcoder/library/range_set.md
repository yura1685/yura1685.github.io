---
title: 区間を set で管理するテク
category: 基礎
description: 整数の集合を互いに重ならない区間の集まりとして持ち、区間の追加・削除や、ある値を含む区間・mex をならし $O(\sqrt{N})$ で求める
order: 7
---

整数の集合を、互いに重ならず隣り合わない半開区間 $[l, r)$ の集まりとして持ちます。区間を加えると、重なる区間や隣り合う区間とつなげます。区間の左端は [SortedMultiset](sorted_multiset.html) で持つので、そのコードも一緒に貼ります。

- `RangeSet()`: 空の集合で初期化
- `add(l, r)`: $l$ 以上 $r$ 未満の整数をすべて加え、新しく加わった個数を返す
- `remove(l, r)`: $l$ 以上 $r$ 未満の整数をすべて取り除き、取り除いた個数を返す
- `get(x)`: $x$ を含む区間 `(l, r)`。 $x$ が入っていなければ `None`
- `x in s`: $x$ が入っているか
- `mex(x)`: $x$ 以上で、入っていない最小の整数（既定は $x = 0$）
- `total`: 入っている整数の個数
- `len(s)`, `for l, r in s`: 区間の個数・区間を左から順に走査
- 計算量: 各操作ならし $O(\sqrt{N})$（ $N$ は区間の個数）

整数を 1 つだけ加えるときは `add(x, x + 1)` とします。

例（ $0$ 以上の整数を 1 つずつ加えながら、その時点の mex を答える）:

```python
s = RangeSet()
for x in a:
    s.add(x, x + 1)
    print(s.mex())
```
